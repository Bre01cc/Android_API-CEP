## Sobre
Projeto desenvolvido com o objetivo de aprender, na prática, como realizar e trabalhar com requisições em APIs.

Foram utilizadas as dependências **Retrofit2** (responsável pelo cliente HTTP) e **Gson Converter** (responsável por converter objetos em JSON e JSON em objetos), facilitando a comunicação entre o cliente e a API.

Durante o desenvolvimento, foram aplicados conceitos importantes como:
- **Interface**: responsável por definir e padronizar as requisições da API;
- **Model**: data class utilizada para representar os dados retornados pela API;
- **Service**: camada responsável por organizar as chamadas de requisição;
- **RetrofitFactory**: configuração e inicialização do cliente Retrofit.

Disciplina ministrada pelo professor [João Henrique](https://www.linkedin.com/in/joao-henrique-parizoti-meyer/?locale=pt_BR).

## Descrição
A aplicação permite consultar informações de endereços a partir de um CEP informado, retornando os dados correspondentes.

Também é possível realizar a busca inversa, informando UF, cidade e rua para obter o CEP e demais informações relacionadas.

Os resultados são exibidos em formato de cards na interface da aplicação.
